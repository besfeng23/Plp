# Retired internal tools (not published)

These legacy staff pages were removed from `public/` in PR 2 (Security and Exposure Fixes) so they are no
longer served. `/content-ops`, `/availability-ops` and `/photo-library` (and their `.html` paths) redirect
to `/admin`. Files are kept here, not deleted, until their useful functions are folded into the unified
administration (plan PR 6/7). Browser persistence of the staff code was removed and must not be restored.

- `content-ops.html` — raw JSON content editor (to be retired; replaced by a controlled content workflow).
- `availability-ops.html` — date blocks (duplicated by Resort Command › Availability in `/admin`).
- `photo-library.html` — photo review grid (to be folded into Growth & Marketing).
